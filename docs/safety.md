# 安全说明

遥操作安全分三层，**不要只依赖其中一层**：

| 层 | 机制 | 说明 |
|---|---|---|
| L1 机器人端 | URScript 限幅/保护 | `ur5_teleop.script` 每周期位姿增量限幅（`MAX_POS_STEP`/`MAX_ROT_STEP`）、关节跳变拒绝、接触/阻塞保护、`servoj` 跟随 |
| L2 主机端 | 状态机 + FT 保护 | 通信超时/帧超时 → 握持失效（HOLD/IDLE）；偏差过大 → 保持；故障 → FAULT 并停程序 |
| L3 现场 | 人 + 硬件 | 急停按钮、工作空间隔离、旁观者远离、低速调试 |

## 上真机前检查

- [ ] `tools/status.py`：安全状态 NORMAL、运行模式 RUNNING、程序可下发
- [ ] `tools/servo_check.py`：0 mm 伺服无异常，再逐级加小步长
- [ ] `config` 中 `workspace_min/max` 已按现场改窄（默认值只作示例）
- [ ] 急停可达；运动路径无杂物
- [ ] 首次运行有人值守，手不离急停

## 已知注意点

1. **保护停 C153A1**：路径偏差/接触类保护停，一旦触发需在控制器解锁后才能继续；
   遥操作中多见于"目标领先实测过多"或撞到桌面。机器人端脚本已加入接触/阻塞保护来降低触发概率。
2. **速度滑块不是安全阀**：实测本控制器在滑块 0% 时 `servoj` 仍会运动，不能当作限速手段。
3. **RTDE 看门狗**：部分 CB3 固件上看门狗触发会进入保护停，默认关闭；由主机侧显式停程序/断连后重连。
4. **回 home 用 `movej`**：servoj 弧线从高位姿态容易逆解跳变；`movej` 到配置 home 更稳，失败会报错。
5. **网线/网络断开**：主机与控柜网络断开时机器人端保持 idle 不动；恢复后需重新下发程序并重新锁存 grip 起点。
6. **急停/失控**：拍急停 → 排查 → 解锁 → 收回工作空间 → 重新初始化，不要直接继续。

## 安全恢复流程

1. 拍急停/保护停 → 停止所有主机侧进程（`Ctrl-C` / 停 supervisor）
2. 控制器解锁（视提示 `unlock protective stop` / 恢复急停按钮）
3. `tools/status.py` 确认安全状态
4. 机器人移回安全位置（手动或 `tools/move_home.py`）
5. 重新下发机器人程序 → 重新开始遥操作
